# Class Schedule · ตารางเรียน

ตารางเรียนรายสัปดาห์ ภาคการศึกษาที่ 2/2569 (Zenless Zone Zero Urban Industrial Pop design system).

## Stack

- [Next.js](https://nextjs.org) (App Router, Turbopack)
- [React 19](https://react.dev)
- [Radix UI](https://www.radix-ui.com) (`@radix-ui/themes` & `@radix-ui/react-icons`)
- [Motion](https://motion.dev)
- Custom CSS design system

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Build

```bash
npm run build
npm run start
```
