ที่มา: วิเคราะห์และวัดสีพิกเซลจริงจากภาพ in-game UI 79 ภาพ (`2560×1440`) ใน `C:\Users\Acer\Pictures\ZZZ_finetune`
ภาพอ้างอิงหลัก: `#03` (Compendium/Schedule), `#05` (N.E.C.F. Quest), `#08`/`#09` (Switch Mode), `#15`/`#24` (Modal & Close Button), `#27` (Announcements), `#28` (Event Calendar), `#30` (Inter-Knot Schedule), `#34` (Data File), `#74` (Polychrome Tracker & Progress Gauge), `#76` (Knock Knock), `#79` (Proxy Info)

## 1. หลักการ

1. **ความอ่านง่ายมาก่อนเสมอ** ชื่อวิชา เวลา ห้อง และกลุ่มเรียนต้องคมชัด ผ่านเกณฑ์ WCAG AA (4.5:1) ลายเซ็นของ ZZZ อยู่ที่กรอบ พื้นหลัง และจุดเน้น ไม่วางทับเนื้อหาที่ต้องอ่าน
2. **ฐานดำ-เทากลางล้วน (neutral matte charcoal)** ไม่อมน้ำเงิน สีเน้นหลักมีเพียงตระกูลเดียวคือเหลือง-มะนาว (`--accent` `#E6D600` ที่ในเกมจะ pulse ระหว่าง `#B8CC00` กับ `#FCDD00`) ใช้น้อยแต่ตัดแรง
3. **Industrial Y2K / Hardware & Cassette** ทุกหน้าจอเป็นวัตถุฮาร์ดแวร์จริง: กรอบหนาซ้อนหลายชั้น ร่องบุ๋มสีดำ (recessed trough) โลหะเทามีตะเข็บ แถบสันแนวตั้ง และแฟ้มกระดาษสีเทาครีมอุ่น (`#C4BFB0`) ไม่ใช่แผงแบน flat และไม่ใช่ Neo-Brutalist hard offset shadow
4. **ภาษาของรูปทรง: มุมโค้งหนา + มุมอสมมาตร ตัดกับแท็บเฉียงในร่อง pill** กล่อง โมดอล และการ์ดในเกมจริงใช้มุมโค้งใหญ่ (`border-radius: 14–26px`) ผสมมุมอสมมาตร (โค้ง 3 มุม อีก 1 มุมโค้งน้อยกว่า) ส่วนความเฉียงอยู่ที่ขอบด้านข้างของแท็บ active ในร่องมืด ไม่ใช้มุมตัด 45° (`clip-path` chamfer) เป็นรูปทรงหลัก
5. **ตัวเลขเป็นพระเอก** (เวลา วัน ห้อง คาบ) ขนาดใหญ่ หนา `tabular-nums`

### 2.3 Class card (ตามแถวกิจกรรมในเกม ภาพ `#28`)

การ์ดวิชาใช้รูปแบบแถวกิจกรรมจากภาพ `#28`: สีประจำวิชาเป็นสีพื้นทั้งการ์ด (ไล่เฉด 135° เบา ๆ) มีขอบในเข้มขึ้น 2px และเส้นไฮไลต์บน 2px, ตัวอักษรดำ `#111111`, ปุ่มกลมดำบอกประเภท `LEC`/`LAB` มุมขวาบน (`LAB` ใช้ตัวอักษรสีวิชา), halftone จางเฉพาะมุมขวาล่างนอกพื้นที่ตัวอักษร
มุมโค้ง 30px (ไม่ใช้ pill เต็มเพราะคาบ 1.5 ชม. กว้างเพียง ~140px) สถานะ `now` / `focus` = วงแหวนดำ 2px + วงแหวน `--accent` 3px นอกการ์ด

**Subject colour tokens (ห้ามซ้ำ `--accent`, `--warn` หรือ `--info` และต้องอ่านตัวอักษร `#111111` ผ่าน AA 4.5:1):**

| `--tone-orange` | `#F57D17` | วัดตรงจากแถวกิจกรรมสีส้มใน `#28` (แยกจาก `--warn` `#FF7000`) |

| `--tone-paper` | `#C4BFB0` | เทาครีมอุ่น วัดจาก `#74` |

### กฎสี
- `--accent` ใช้ไม่เกิน ~10% ของพื้นที่หน้า เฉพาะ active, focus, CTA และวันนี้
- `--warn` / `--danger` / `--info` / `--success` ใช้ตามความหมายเท่านั้น ห้ามใช้ประดับ
- สีประจำวิชาใช้ระบายเต็มการ์ดตาม §2.3 (และใช้เป็นแถบสีประจำรายชื่อวิชาใน `COURSE FILES` / `Dossier`) ห้ามใช้สีเดียวกับ `--accent`
- ห้าม gradient ม่วง-ชมพู, ห้ามใช้สีขาวบริสุทธิ์เป็นพื้นหลังแผงใหญ่ (ยกเว้นการ์ดแฟ้มแบบกระดาษ `--paper` `#C4BFB0` เป็นจุดเน้น)

## 3. Typography

| บทบาท | สไตล์ | ตัวอย่าง |
|---|---|---|
| Display | Anton (หนามาก condensed ตัวพิมพ์ใหญ่ เอียงได้ `skewX(-8deg)`) | หัวหน้า, ชื่อวัน, `WEEKLY SCHEDULE` |
| Numeral | หนา tabular (`font-variant-numeric: tabular-nums`) | เวลา, วันที่ `23/11 MON`, นับชั่วโมง |
| Body | Prompt (sans-serif รองรับภาษาไทย) น้ำหนัก 400 / 600 / 800 | ชื่อวิชา, ห้อง, รายละเอียดใน Dossier |
| Label | uppercase ตัวเล็ก letter-spacing กว้าง หรือ monospace | `ROOM`, `SEC`, `DATA FILE`, serial stamp |
| Watermark | display ขนาดยักษ์ opacity 4–8% (เอียงได้) วางหลังแผง | `WK47`, `DATA FILE`, `SCHEDULE` |

กฎ: หัวข้อภาษาอังกฤษตัวพิมพ์ใหญ่เป็นกราฟิกคู่กับข้อความไทย ข้อความไทยใช้ Prompt ตรงเสมอ ห้ามเอียงเทียม (`skew`/`italic`) กับข้อความไทย และไม่ใช้ display font กับข้อความไทยยาว (ตรงกับวิธีแสดงภาษาไทยในเกมทั้ง 79 ภาพ)

## 4. รูปทรงและกรอบฮาร์ดแวร์ (Shape & Hardware Language)

- **กล่อง / โมดอล / แผงหลัก:** สี่เหลี่ยมมุมโค้งหนา (`border-radius: 16–26px`) พร้อม **มุมอสมมาตร** (โค้ง 3 มุม อีก 1 มุมโค้งเล็กกว่า เช่น `24px 10px 24px 24px` ตาม `#15`, `#24`, `#28`, `#76`) ไม่ใช้มุมตัด 45° (`clip-path` chamfer) เป็นรูปทรงหลัก
- **กรอบซ้อนชั้น (Chunky Hardware Framing):** แทนที่ hard offset shadow แบบ brutalist (`4px 4px 0 #000`) ด้วยกรอบซ้อนชั้นแบบเกมจริง: ขอบนอกสี `--line` 2–3px + เส้นดำ `#000` 2–3px + เส้นไฮไลต์ขอบบนบาง ๆ (`inset 0 1px 0 rgba(255,255,255,0.1)`) และร่องบุ๋มสี `--bg-void`
- **แถบแท็บและกลุ่มตัวกรอง (Tab Trough):** วางในร่อง pill สี `--bg-void` ขอบ `--line` 2px แท็บ active เติมสี `--accent` พร้อมขอบด้านข้างเฉียง (~15–20°) และปลายมน (`#03`, `#05`, `#27`, `#28`, `#30`, `#74`)
- **ปุ่ม / chip / toggle:** pill สีดำหนา (`--bg-void` / `--bg-raised`) ในขอบเทา 2px (ไม่ใช่เส้นบาง 1px พื้นใส) สามารถใส่ badge วงกลมไอคอนสีฝั่งซ้ายสำหรับปุ่มแอ็กชันสำคัญ (`#23`, `#24`, `#30`)
- **ปุ่มปิด (Close button):** สี่เหลี่ยมมนแนวนอนเอียง/อสมมาตร (tilted squircle กว้างกว่าสูง) พื้น `--close-bg` (`#C01C00`), ขอบสว่าง `--close-rim` (`#E3421F`), **กากบาท `×` สีดำหนา** วางในร่องมืดมุมขวาบน (`#15`, `#24`, `#27`, `#28`, `#68`, `#70`, `#76`) — ไม่ใช่วงกลมแดงกากบาทขาว
- **ช่องว่าง (Empty slot):** กล่องพื้นทึบมืด/เทา มี **กากบาท `X` หนาตรงกลาง + ป้าย `EMPTY` หรือ `NO CLASS`** ด้านล่าง (`#05`, `#15`, `#34`) ไม่ใช้กรอบเส้นประ `dashed`
- **Focus ring:** วงแหวนดำ 2px + วงแหวน `--accent` 3px รอบวัตถุ

## 5. Signature elements (ตรงตามเกมจริง ใช้อย่างประหยัด)

1. **พื้นหลังลายทางทแยง 45° สีดำ-เทาเข้ม:** `repeating-linear-gradient(45deg, var(--shell-a) 0 6px, var(--shell-b) 6px 8px)` ใช้กับพื้นหลังหน้าและเปลือกกรอบ (`#15`, `#24`, `#27`, `#28`, `#76`) แทนที่ hazard stripe เหลือง-ดำ (ซึ่งแทบไม่ปรากฏใน UI เกมจริงทั้ง 79 ภาพ)
2. **ลายจุดละเอียด (Micro-dot / Halftone):** ในแถบหัวโมดอล (`#15`, `#24`, `#27`, `#76`) และมุมขวาล่างของการ์ด/VHS นอกพื้นที่ตัวอักษร
3. **ป้าย `NEW!` / Status tag:** ตัวอักษรเอียงสี `--accent-tag` (`#FFFF04`) ขอบดำหนาลอยมุมซ้ายบนของแท็บหรือการ์ด (`#03`, `#15`, `#27`, `#28`, `#30`, `#74`, `#76`) ส่วนป้ายสถานะหมวดหมู่ใช้ pill ขอบดำหนา (`#74`)
4. **ข้อความแนวตั้งหมุน 90°:** สันข้างแผง เช่น `SCHEDULE` (`#03`), `DATA FILE` (`#34`), `NOW PLAYING // SIDE A`
5. **Serial / barcode stamp:** รหัสเล็ก ๆ แบบ monospace มุมแผงและหัว Dossier
6. **Chevron `>` และ `>>`:** ลาย chevron ในแถบ progress (`#74`), ปุ่มกลมดำมีลูกศรฝั่งขวาแถว (`#28`) และตัวคั่นหัวข้อ
7. **ร่องบุ๋มฮาร์ดแวร์ + เส้นตะเข็บ dashed + binding tabs:** ตาม `#03`, `#28`, `#74` (แทนที่ film grain)
8. **ตัวอักษรยักษ์เอียงจาง (Ghost Watermark):** ด้านหลังแผง opacity 4–8% (`#15`, `#24`, `#28`, `#30`, `#76`)

## 6. State และ motion

| State | พฤติกรรม |
|---|---|
| Inactive | ข้อความ `--text-muted`, พื้น `--bg-void` หรือ `--bg-panel`, ขอบ `--line` |
| Hover | พื้น `--bg-hover`, ขอบสว่างขึ้นเป็น `--line-strong`, การ์ดขยับ `translate(-2px, -2px)` หรือเพิ่ม brightness เล็กน้อย |
| Active / Focus | แท็บ/ปุ่มเติม `--accent` ตัวอักษร `--accent-ink`; การ์ด/ช่องโฟกัสใช้วงแหวนดำ + `--accent` 3px |
| Active-tab pulse | แท็บที่เลือกสามารถกระพริบช้า ๆ ระหว่าง `--accent-lime` (`#B8CC00`) ↔ `--accent-peak` (`#FCDD00`) เหมือนในเกม (`#27`–`#30`–`#74`–`#76`) และปิดอัตโนมัติเมื่อเปิด `prefers-reduced-motion` |
| Today | แท็บวัน active สี `--accent` ขอบซ้ายเฉียง + ป้าย `TODAY` + เส้น `NOW` |
| Transition | เร็วและคม `120–180ms`, easing แบบ snap (`cubic-bezier(.2, .9, .2, 1)`), ไม่ bounce นุ่ม |
| Enter | slide เฉียงเข้า (`translate + skew`) แบบ stagger ทีละการ์ด (`40ms`) |

ต้องรองรับ `prefers-reduced-motion` ทุกแอนิเมชัน (รวมถึง `EncryptedText` และ active-tab pulse)

## 8. Do / Don't

**Do**
- ใช้ `--accent` เฉพาะ active, focus, CTA และวันนี้ (≤ 10% ของพื้นที่)
- ใช้กรอบฮาร์ดแวร์มุมโค้งอสมมาตร ขอบหนาซ้อนชั้น และร่องบุ๋มสีดำคู่กับแท็บเฉียง
- ใช้ตัวเลขใหญ่ หนา `tabular-nums`
- ตรวจสอบคอนทราสต์ข้อความให้ผ่าน WCAG AA (4.5:1) ทั้งโหมดปกติและบนสีประจำวิชา
- ใช้ CSS custom properties จาก §2 ทั้งหมด ไม่ hardcode hex ในคอมโพเนนต์หรือ CSS

**Don't**
- ห้ามใช้มุมตัด 45° chamfer หรือ hard offset shadow `4px 4px 0 #000` เป็นสไตล์หลัก
- ห้ามใช้ปุ่มปิดวงกลมสีแดงกากบาทขาว (ให้ใช้สี่เหลี่ยมมนเอียงสี `--close-bg` กากบาทดำ)
- ห้ามใช้ hazard stripe เหลือง-ดำประดับหน้า หรือใช้ film grain แทนลายทางทแยงมืด
- ห้ามใช้ shadow นุ่มฟุ้ง, glassmorphism, หรือ gradient ม่วง-ชมพู
- ห้ามใส่ลายเซ็นครบทุกอย่างในจุดเดียวจนรก และห้ามวาง halftone ทับข้อความที่ต้องอ่าน
- ห้ามใช้ emoji, ห้ามข้อความโฆษณา, ห้ามเอียงฟอนต์ไทยหรือ scramble ข้อความไทย
